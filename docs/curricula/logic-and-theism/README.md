## Mapping rule

A chapter map is not a summary. It should identify:

- durable concept/capability nodes;
- source-local terminology that must not overwrite canonical concepts;
- prerequisite dependencies;
- concrete-to-formal Externalize interactions;
- likely learner error modes;
- Reading vs Mastery exits;
- reusable exercise families;
- architectural findings exposed by the source.

Whenever the source wording or argument is not yet inspected closely enough, the map must say so rather than fill gaps from generic philosophy knowledge.
