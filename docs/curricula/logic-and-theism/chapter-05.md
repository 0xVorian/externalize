# Chapter V — First Causes: “The Second Way”

**Source:** Jordan Howard Sobel, *Logic and Theism*, Chapter V, pp. 168–199  
**Status:** reviewed  
**Role in source-driven curriculum:** first major shift from modal/theorem reasoning to causal/dependency structure

## Why this chapter matters for Externalize

Chapter V is a strong test of whether Externalize can change representational modes without fragmenting the curriculum. Chapters III–IV are naturally taught with possible-world cards, modal operators, and theorem-dependency graphs. Chapter V instead asks the learner to reason with **relations, causal chains, regress structure, uniqueness, and temporal vs sustaining dependence**.

The reusable lesson is not “learn Aquinas.” It is how to inspect an argument whose validity depends on the exact structure and interpretation of a relation.

A central pedagogical theme should therefore be:

> **Draw the dependency structure before evaluating the prose.**

## V.1 — Aquinas’s project and demonstration *quia*

**Source focus:** Sobel situates the Second Way as an argument from effects or sensible things toward a first efficient cause. The intended final answer is to the present-tense question whether God exists.

**Requires**

- argument from observed premise;
- deductive proof vs explanatory hypothesis;
- existential claim.

**Externalize sequence**

1. **Prerequisite:** distinguish `I observe E` from `I infer C because C is the only possible explanation of E`.
2. **Derive:** give a visible dependency chain and ask what follows from the existence of its terminal effect alone.
3. **Interrogate:** ask what would make such an argument demonstrative rather than merely evidential.
4. **Predict:** before the articulation, ask which premises would be needed to force a first cause.

**Reading exit:** learner understands the target: a deductive path from sensible causal structure to a presently existing first cause identified with God.

## V.2 — Sobel’s articulation of the Second Way

Sobel reconstructs the argument using seven premises, a preliminary conclusion, an identification premise, and the intended conclusion.

### Structural skeleton

1. Some sensible things have efficient causes.
2. If a thing has an efficient cause, it has exactly one efficient cause.
3. Efficient causes are prior to their effects.
4. Priority is irreflexive: nothing is prior to itself.
5. Priority is transitive.
6. Every sensible thing that efficiently causes a sensible thing itself has an efficient cause.
7. Regresses of efficient causes cannot be infinite.
8. Therefore there is a first cause for sensible things with efficient causes, with no efficient cause of its own and not itself sensible.
9. This is what everyone correctly calls God.
10. Therefore God exists.

The exact formal details are useful in Mastery depth, but Reading depth should first make the **graphical commitments** visible.

### Externalize interaction: build the argument as a graph

Display the premises as toggles that constrain a causal graph:

- `unique incoming cause`;
- `cause ≠ effect`;
- `priority transitive`;
- `no uncaused sensible internal node`;
- `no infinite backward path`.

Then ask the learner to generate or inspect graphs satisfying all selected constraints.

This should expose an important fact before Sobel states it: these constraints can force a first node on each backward chain without forcing **one shared first node for all chains**.

### Likely stumbling blocks

- reading “a first cause” as automatically unique globally;
- assuming a tree must have one root;
- confusing irreflexivity with asymmetry or acyclicity;
- treating `no infinite chain` as already proving that all chains merge.

**Reading exit:** learner can reconstruct what each premise contributes to the graph.

**Mastery exit:** learner can symbolize the premises and identify which are relational, existential, and universal.

## V.3 — What kind of efficient cause: generating or sustaining?

This is one of the chapter’s richest Externalize targets.

Sobel distinguishes two candidate interpretations:

- **generating causes**: causes that bring something into existence or produce it; they can precede their effects and cease to exist while the effect remains;
- **sustaining causes**: causes on which something depends here and now; they are concurrent with the effect while the dependence obtains.

Sobel’s central interpretive tension is that the **generating** reading fits the initial observational premise and Aquinas’s wording better, while the **sustaining** reading performs better later: it gives more plausibility to the anti-regress claim, aligns better with other Aquinas texts, and can support a presently existing first cause.

### Externalize sequence

1. **Derive generating causation:** `parent → child`, `builder → building`, `star explosion → remnant`.
2. Ask whether the cause must still exist when the effect exists.
3. **Derive sustaining dependence:** `powered server → running process`, `magnetic field → suspended object`, `load-bearing support → supported load`.
4. Ask whether the dependency can survive removal of the cause.
5. Present the same chain visually in two modes: horizontal time-line vs vertical concurrent dependency stack.
6. Re-run premises (1), (6), and (7) under each interpretation.
7. Ask which interpretation makes each premise more plausible.

### High-value transfer exercise

Give the learner a mixed graph containing both kinds of edges and ask them to label each edge before reasoning about regress. This prevents “cause” from being treated as a single unanalyzed relation.

### Important curriculum finding

`causal-relation` should not be a single terminal concept node. Externalize needs **edge semantics**. The same graph topology can support materially different arguments depending on what an edge means.

**Reading exit:** learner can explain why a generating-cause and sustaining-cause version of the Second Way are not merely two examples of the same argument.

## V.4 — Infinity and infinite regress

Sobel treats the anti-infinite-regress premise as the heart of the argument.

### Distinctions to teach

- actual infinite collection vs endless process;
- infinite temporal past vs infinite concurrent dependency chain;
- “cannot traverse an infinity” argument vs an actually beginningless sequence;
- impossibility of a regress vs absence of a first member.

Aquinas himself, as Sobel stresses, rejects a crude traversal argument against an infinite temporal past: once a starting point in the past is specified, only finitely many intervals separate it from now. Sobel uses this to block a popular argument against an infinite sequence of generations.

At the same time, Aquinas is more sympathetic to impossibility of an infinite **per se/concurrent** dependence chain, and Sobel explores Aquinas’s separate argument against actually infinite multitudes.

### Externalize sequence

1. **Timeline task:** show `... → t-3 → t-2 → t-1 → now` with no first time. Ask “what had to be traversed from the beginning?” Correct answer: the scenario has no beginning point.
2. Give a chosen earlier time `t-1000`; ask how many steps separate it from now.
3. **Concurrent chain task:** `stone ← stick ← hand ← ...` and ask what kind of dependence remains unresolved if every link’s present activity derives from another present link.
4. Ask whether the same objection applies to both chains.
5. Build finite and infinite graphs; explicitly mark whether first members exist.
6. Separate: `infinite regress is impossible` from `this particular infinite regress is impossible`.

### Counterexample mode

Let the learner construct an infinite generating chain consistent with all local causal rules except premise (7). This makes clear that premise (7), rather than the relational rules, is doing the termination work.

### Reading exit

Learner can state why “we would never arrive at the present” is not by itself a good objection to a beginningless temporal series, and why a sustaining regress raises a distinct question.

## V.5 — The preliminary conclusion: distributive vs collective first cause

This section is an exceptionally clean logic lesson.

Sobel distinguishes, in effect:

- **(8a)** for every relevant sensible thing, there is a first cause of that thing;
- **(8b)** there is exactly one thing that is the first cause of every relevant sensible thing.

Premises (1)–(7), at best, yield the first. They do not establish the second. Distinct causal chains may terminate in distinct first causes.

### Externalize sequence

1. Show four effects `y1..y4` with four separate backward chains ending at `x1..x4`.
2. Ask whether `each yi has a first cause` is true.
3. Ask whether `there is one x that is first cause of every yi` is true.
4. Merge some roots; repeat.
5. Merge all roots; repeat.
6. Translate the difference into quantifier order only after the graph intuition is stable.

### Formalization target

The exact formulas are less important than the order distinction:

- `∀y ∃x ...`
- `∃x ∀y ...`

This gives Externalize a reusable **quantifier-order exercise family** that is much more motivated than arbitrary textbook examples.

### Transfer examples

- every employee has a manager vs one manager manages every employee;
- every file has an owner vs one owner owns every file;
- every theorem has a proof vs one proof proves every theorem.

### Reading exit

Learner can spot the global-uniqueness strengthening immediately from a causal diagram or quantifier order.

### Mastery exit

Learner can construct a countermodel satisfying (8a) and falsifying (8b).

## V.6 — The explicit gap

Premise (9), which identifies “the” first cause as God, needs a unique referent. But Sobel argues that the previous premises do not produce one.

He formulates the missing bridge as a further principle: if every relevant sensible thing has a first cause, then there is exactly one first cause common to all of them. Aquinas supplies no adequate reason for that bridge.

### Externalize sequence

1. Keep the causal graph from V.5 visible.
2. Highlight the phrase “to which” or “this first cause” as needing a single target node.
3. Ask the learner to point to that node.
4. In a multi-root graph, make the UI refuse the reference because no unique node is licensed.
5. Ask what additional premise would make the reference well-defined.
6. Distinguish **repairing validity** by adding a premise from **showing the added premise is true**.

This is a strong general-purpose lesson in argument repair: a missing premise can make an argument valid without making it sound.

**Reading exit:** learner can name the missing uniqueness premise rather than vaguely saying “Aquinas hasn’t proved God.”

## V.7 — Even if there were one first cause, does God exist now?

Sobel adds another separation that should become a durable Externalize habit: **the temporal strength of the conclusion**.

If the argument is about generating causes, a first generating cause could have done its work and ceased to exist. The conclusion `there was a first generating cause` does not entail `a first generating cause exists now`.

A sustaining-cause version avoids this particular problem because sustaining causes are concurrent by definition: a presently sustained effect requires a presently operative sustaining cause.

But the sustaining version paid for this advantage earlier, because Sobel doubts that the initial observational premise is adequately established for sustaining causes.

### Externalize sequence

1. Give a generating chain whose earliest cause is deleted after producing the next member. Ask whether the downstream effect can remain.
2. Give a sustaining dependency stack and delete the top support. Ask whether the target persists under the stipulated semantics.
3. Translate:
   - `∃t < now: firstCauseExists(t)`
   - `firstCauseExists(now)`
4. Ask which premises warrant each.
5. Return to Aquinas and ask which conclusion his theological target requires.

### Important curriculum finding

Externalize needs to track **conclusion tense / temporal scope** explicitly in source-driven arguments. A proposition can look verbally close to the target while still be weaker in temporal content.

**Reading exit:** learner can explain why the generating-cause reading and sustaining-cause reading trade strengths and weaknesses rather than one simply dominating the other.

# Appendices

## Appendix A — Aquinas’s other Ways

Useful as **transfer**, not as a new mandatory branch.

The Third Way is especially valuable because it reprises two reusable errors:

- modal confusion between `is contingent` and `at some time does not exist`;
- quantifier-order movement from `for everything, there is some time when it does not exist` to `there is some time when nothing exists`.

The Fourth Way supplies a maximum-from-comparison mistake: `some things are more F than others` does not entail a maximum F exists.

These can be tagged as transfer challenges for concepts already learned elsewhere.

## Appendix B — Big Bang and kalām

Useful for distinguishing several senses of `begins to exist` and for revisiting the infinite-past issue.

### Candidate exercise

Construct a timeline with an earliest time but no object existing at that first instant. Ask whether “the universe began to exist” is true in different senses and what causal premise is needed for each.

This is a good **semantic-disambiguation** exercise rather than a new logic primitive.

# Reading route for Chapter V

A minimal just-in-time path should be:

```text
binary relation
  -> directed causal graph
  -> generating vs sustaining edge semantics
  -> irreflexive/transitive priority
  -> finite vs infinite chain
  -> first member
  -> ∀∃ vs ∃∀ uniqueness
  -> temporal strength of conclusion
```

The learner does **not** need full predicate-logic derivations before reading the chapter intelligently. Quantifier-order formalization can be introduced precisely at §5, where it becomes useful.

# Mastery route

Adds:

- symbolize premises (1)–(7);
- inspect the relation axioms formally;
- construct models with multiple independent roots;
- prove that the premises can support per-chain first causes without a global first cause;
- formalize generating vs sustaining versions using temporal predicates if desired;
- audit appendices as transfer cases.

# Architectural findings from Chapter V

1. **Graphs need typed edges.** Topology alone is not enough; generating and sustaining causation behave differently.
2. **Source routes may introduce a representation before notation.** A causal graph should precede predicate-logic symbolization here.
3. **Quantifier lessons can be demand-driven.** `∀∃` vs `∃∀` is much easier to care about when it diagnoses Sobel’s actual gap.
4. **Argument state should preserve target strength.** The system should show when the current derivation establishes a weaker existential, uniqueness, modal, or temporal claim than the source’s target.
5. **Interpretive alternatives should be first-class.** The same textual argument can be run under generating and sustaining semantics and compared premise by premise.

# Validation target

A learner has understood the chapter at Reading depth if, without the text, they can explain four independent questions:

1. Why does the kind of efficient cause matter?
2. What does the anti-infinite-regress premise actually contribute?
3. Why does `every causal chain has a first member` not imply `all chains share one first member`?
4. Why might a first generating cause fail to establish that God exists now?

If Externalize can get the learner to those four distinctions through interactive graphs before Sobel states them, this chapter strongly validates the source-driven approach.
